# AudioEffectLowShelfFilter

**Inherits:** [AudioEffectFilter](class_audioeffectfilter.md#class-audioeffectfilter) **<** [AudioEffect](class_audioeffect.md#class-audioeffect) **<** [Resource](class_resource.md#class-resource) **<** [RefCounted](class_refcounted.md#class-refcounted) **<** [Object](class_object.md#class-object)

Adds a low-shelf filter to an audio bus.

## Description

A "low-shelf" filter controls the gain of all frequencies below [AudioEffectFilter.cutoff_hz](class_audioeffectfilter.md#class-audioeffectfilter-property-cutoff-hz).

This filter can be used to adjust the "strength" of a sound, by increasing or decreasing its low-end.
